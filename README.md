---

## ✏️ The Hand-Drawn Standard (and Where We Stand on AI)

> *"Off the rip, we refused to use AI for anything generative. So every design that we make is hand-drawn and with intentionality and authenticity."*

- **100% Hand-Drawn Artistry:** We reject generic stock vectors, canned templates, and generative AI imagery. Every identity begins with pencils and ink—starting from client keywords, exploring 10 to 25 custom illustrations, and distilling them into 3 distinct, fully mocked-up concepts.
- **Where Technology Fits:** We leverage advanced automation, AI-driven code verification, and rigorous performance audits for web engineering and technical workflows. But when it comes to the forward-facing artistic mark that represents your business, it is hand-crafted with human soul.
- **True Ownership:** When an identity project concludes, 100% of the trademark-ready copyright passes directly to the brand owner.
